# Medical Imaging AI for Brain Tumor Diagnosis

## Project Overview
This project focuses on classification and segmentation of brain tumors from MRI images using deep learning techniques. The system is designed to support accurate medical diagnosis and automated report generation.

---

## Technologies Used
- Python
- TensorFlow
- ResNet50
- OpenCV
- PyTorch
- U-Net
- Raspberry Pi

---

## Features
- Brain tumor classification
- Tumor segmentation using U-Net model
- MRI image analysis
- AI-assisted diagnosis
- Automated medical report generation
- Portable implementation using Raspberry Pi

---
## Deep Learning Models Used
### ResNet50
Used for brain tumor classification from MRI images.

### U-Net
Used for accurate tumor region segmentation and localization.
